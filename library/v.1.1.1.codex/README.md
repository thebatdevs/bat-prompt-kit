# Development Variants

This directory contains development-only reference inputs for Bat-Peasant maintainers.

It is not part of the installed v1.1.0-codex persistent-context tree. Activated workflows must use `.agents/` and must
not search or load files from `variants/`.

Content becomes supported release authority only after it is reviewed, consolidated into `.agents/`, and validated
there. A file under `variants/` never overrides or supplements `.agents/` merely because it is unique or more detailed.

Retain unique material here only while evaluating it for consolidation or removal. Do not add new shadow copies of
canonical `.agents/` files.
